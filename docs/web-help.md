# 网页帮助内容

此文件是网页帮助文案的可编辑副本；正式页面位于 frontend/index.html 的 help-panel。改本文不会自动更新页面。

AutoLandscape 是基于 SaddleScape 软件包的解景观研究智能体。AI 帮你理解问题、配置任务和解读结果，数值计算由服务器执行，并由你确认后开始。

## 第一次使用：按这条流程走

登录 → 提问 → 载入模板 → 保存草案 → 提交复核 → 确认计算 → 查看结果。不熟悉参数可以先问助手，不需要先选任务。

## 1. 与助手对话

勾选外部 AI 服务同意，输入问题并点发送箭头（Enter 发送，Shift + Enter 换行）。例如：“HiSD 的 target_index 是什么意思？”回答支持公式、表格和代码复制。

要检查配置，勾选“附带当前草案”；要分析结果，打开正确任务并勾选“附带选中任务”。未选任务也能普通对话，本轮不会读取任务信息。

## 2. 配置并应用建议

在“配置新任务”中选择并载入模板。修改表单后点击“保存参数到草案”，提交以 JSON 为准。需要 AI 建议时，附带草案、取消附带任务，再点“生成配置草案”。检查改动后明确应用，应用不会开始计算。

## 3. 复核后确认计算

点击“提交方案复核”，等待服务器检查。方案就绪后阅读模型、参数和资源预算，勾选确认再开始计算。等待领取可能约两分钟；取消也需等待服务器处理。

## 4. 查看任务与结果

侧栏任务在右侧打开，可与对话并排。关闭 AI 可扩大任务视图，点“AI 对话”可恢复。检查摘要、验证与最近日志；计算完成不等于景观完整，搜索连接不自动等于物理转变路径。

“导出任务记录”保存 JSON 快照与末尾日志。当前完整结果文件存储尚未开放，不能据此下载全部搜索日志。从已验证节点发起新计算仍需复核与确认。

## 会话与常见问题

当前只保留一个临时对话。新对话前会提示清空，普通刷新保留登录与已收到消息；连续30分钟无操作或退出后清除。刷新后需重新勾选 AI 同意。

澄清也使用主模型次数；明确无关请求累计超过管理员阈值会暂停当天 AI。每日额度北京时间上午8点恢复。等待超时不代表后台已停止或额度已退回，请勿立即重复发送。

目前不支持对话附件和多个历史聊天；“导入 JSON”只用于任务配置。模型、资源或结果有疑问时，先查看任务提示，再请助手解释。
