# 快速开始

**如需完成一次计算，可按以下顺序操作：登录 → 问一个问题 → 载入模板 → 检查草案 → 提交复核 → 确认计算 → 查看结果。** 不熟悉参数时先与助手讨论，无须先选择任务。已有任务可以直接用于结果解读。

| 你现在想做什么 | 从哪里开始 | 下一步 |
|---|---|---|
| 了解方法或参数 | AI 对话 | 勾选外部服务同意，输入问题并点击发送箭头 |
| 开始一个计算 | 配置新任务 | 载入模板，保存参数到草案，提交复核 |
| 检查已有计算 | 已提交任务下的列表 | 选中任务，展开最近日志和结果摘要 |
| 请 AI 看当前草案 | AI 对话下方 | 勾选“附带当前草案”，先把表单修改保存到草案 |
| 请 AI 解释已提交任务 | 打开该任务后 | 勾选“附带选中任务”，明确要分析哪个问题 |

第一次提问没有固定格式，可以直接描述你的研究目标。如果想先熟悉助手，**例如可以输入**：“HiSD 中的 target_index 是什么意思？”

你也可以输入：“我想研究一个相场模型，请先帮我明确模型、边界条件和计算目标。”助手会根据已提供的信息解释或继续询问。无需先发送寒暄或规定的测试问题。

# 1. AutoLandscape 是什么

AutoLandscape 是面向解景观研究的网页智能体工作台。它使用 **SaddleScape Python 软件包**执行 HiSD 及相关数值计算，将研究问题讨论、任务配置、人工确认和结果查看连接起来。

AI 助手负责解释、建议和受限的草案生成。任务复核与计算由后台和计算服务器完成。用户可以先交流想法，再决定是否计算；AI 的一条回答不会自动启动求解器。

SaddleScape 软件包支持的研究方法与网站当前开放的功能不是同一份清单。论文中的方程或方法，不一定已经被网站实现。首次使用请从网页公开模板开始，自定义模型需要先核对实际执行能力。

## 1.1 三个容易混淆的对象

| 对象 | 含义 | 怎样改变 |
|---|---|---|
| 当前草案 | 配置页中准备提交的 JSON | 编辑表单后保存，或应用 AI 的配置建议 |
| 已提交任务 | 已经提交到服务器的记录 | 修改草案不会改变它，需要另建任务 |
| 复核方案与计算结果 | 服务器解释并复核后的方案，以及该任务的输出 | 阅读方案并确认后计算，以该任务信息为准 |

模板下拉框的选择也不等于草案已经改变。切换模板后还需要点击“载入模板”。

## 1.2 当前能力

可以直接对话、解释草案、生成允许字段的修改建议、读取选中任务的有限摘要、提交复核并确认计算、查看任务状态与最近日志、导出任务记录，以及从已验证节点发起新计算。

当前只有一个临时对话，不提供多个历史聊天。对话不支持 PDF、图片或 Word 附件，也尚未提供可靠的论文检索。结果文件下载依赖结果存储是否开放；目前该存储尚未开启。上述限制不影响文字对话和任务记录导出。

# 2. 登录与界面

## 2.1 登录

使用管理员提供的个人访问令牌。把令牌输入登录页，点击“进入工作台”。不要把令牌发送给 AI，或放进截图、任务说明与配置文件。

普通刷新会保留当前标签页的登录和已收到的临时对话消息。恢复时网站会再次核验身份。连续 **30 分钟没有操作**后需要重新登录；后台自动刷新任务状态不会延长这个期限。

刷新后需重新勾选外部 AI 服务同意，并重新检查附带草案或任务的选择。尚未保存的参数、未发送的问题及 AI 配置建议不保证恢复。关闭标签页通常结束临时会话，浏览器自身的会话恢复行为可能不同。

退出入口在左下角用户菜单。退出会清除本标签页的令牌和临时对话，已经提交的计算任务不会因此取消。

## 2.2 找到入口

左侧依次是“AI 对话”“配置新任务”“已提交任务”。缩进列表中的每一项是计算任务，不是历史聊天。底部提供“帮助与使用指南”和用户菜单。

默认页面是对话，用户消息在右、助手消息在左。点击一个任务后，右侧出现详情，左侧仍可对话。关闭 AI 面板可扩大任务视图，点击“AI 对话”可重新打开；关闭任务面板可回到完整对话。

手机或窄窗口通过左上角菜单展开侧栏。任务与对话可能上下显示。

# 3. 与助手交流

## 3.1 普通对话

1. 勾选“同意将本次对话及勾选的资料发送至外部 AI 服务”。
2. 输入与模型、算法、任务配置或结果有关的问题。
3. 点击发送箭头，或按 Enter。Shift + Enter 换行。
4. 等待回答。发送中不要反复提交同一问题。

**没有选中任务也能直接对话。** 若勾选了附带任务但未选任务，本轮会继续普通交流，并提示没有选择任务。助手此时没有读取任何已提交任务。

“生成配置草案”是另一种操作。单纯询问概念时请使用发送箭头，不需要生成草案。

## 3.2 更容易得到有用回答的问法

- 概念：“解释 target_index，并区分搜索单个驻点与构建解景观。”
- 草案检查：“请只检查当前草案的初始点维数和资源设置，不修改。”
- 任务诊断：“请根据本轮选中任务说明失败阶段、已有证据和下一步检查。”
- 结果解读：“请区分节点验证通过、搜索连接与景观完整性，缺少的证据请明确指出。”

对于尚不明确的物理问题，可以先描述研究对象和目标，再让助手询问必要的方程、离散与边界。无需一开始就掌握全部字段。

回答支持加粗、列表、表格、数学公式和代码块。代码块可一键复制；公式不能替代数值验证。

## 3.3 附带草案与任务

| 选择 | 发送什么 | 使用前检查 |
|---|---|---|
| 附带当前草案 | 当前编辑框 JSON 与模板选择 | 表单修改是否已保存到草案 |
| 附带选中任务 | 当前任务状态、部分提交配置、近期日志、错误与结果摘要等 | 是否选中了正确任务，是否勾选附带 |

任务资料是有限快照，不是完整文件。助手不会自动读取本地文件、所有历史任务、完整搜索日志或结果图片。界面“说明”中的回执可帮助确认本轮附带对象；AI 自称已读取，不等于程序确认。

普通对话可同时附带两种资料，但应说明问题针对哪一种。生成配置草案时只能针对当前草案，请取消附带已提交任务。

## 3.4 临时对话与额度

当前只保留一个临时对话。开始新对话前，有现有消息、未发送内容或配置建议时会弹出清空确认；取消可保留，确认后无法恢复。普通刷新可恢复已经收到的消息，退出或会话过期后清除。

发送给模型的历史上下文有长度限制，较早的内容可能不再参与本轮回答。关键模型信息应通过当前草案或任务快照再次提供。

正常问题和需要进一步澄清的问题都会使用主模型额度。明确无关的问题会被拒绝并累计违规，不调用主模型；默认累计超过 10 次暂停当天 AI，具体阈值由管理员设置。每日额度按北京时间上午 **8 点**恢复，不是午夜。

# 4. 配置一个任务

## 4.1 从模板开始

进入“配置新任务”，选择模板并点击“载入模板”。以下是当前交付版本的公开目录，实际开放情况以网页与复核结果为准。

| 模板 | 自由度 | 用途或限制 |
|---|---:|---|
| Butterfly 蝴蝶势能 | 2 | 梯度系统示例 |
| Müller–Brown 势能 | 2 | 梯度系统示例 |
| Cubic 三维 | 3 | 梯度系统示例 |
| 二维双阱 | 2 | 梯度系统示例 |
| 非梯度示例 | 2 | 指标应按不稳定子空间理解 |
| 周期相场 8×8（实验） | 64 | 固定离散示例，不代表任意网格或边界已开放 |

初次尝试建议保留模板的数值设置、使用 1 个 CPU 线程，并根据研究目的检查目标指标。不要把别的任务中的资源上限当作所有服务器的固定上限。

## 4.2 先认识这些参数

| 参数 | 含义 | 首次使用的注意点 |
|---|---|---|
| target_index | 目标驻点指标 | 非退化梯度系统中为 Hessian 负特征值个数 |
| initial_point | 初始点 | 元素个数必须与系统维数一致 |
| timestep | 迭代步长 | 太大可能不稳定，太小可能较慢 |
| tolerance | 求解器停止精度 | 与结果验收阈值不是同一个概念 |
| max_iterations | 迭代上限 | 是预算，不保证收敛 |
| perturbation_radius | 扰动尺度 | 改变探索起点，不能保证找到更多不同解 |
| cpu_threads、memory_mb | CPU 与内存预算 | 还要满足计算服务器的管理员限制 |
| walltime_seconds | 时间预算 | 到上限可能停止，不应据此自动续跑 |

二维梯度系统的 index 0、1、2 分别对应局部极小、一阶鞍点和局部极大（非退化情形）。HiSD 搜索时沿所选不稳定方向爬升；“极大点沿负曲率方向能量下降”描述的是能量形状，不能把二者混用。

构建解景观可以从高指标驻点向低指标搜索，因此目标为 2 或 3 并不自动意味着设置错误。先确认研究目标，再判断指标。

非梯度系统按 Jacobian 特征值实部为正的不稳定子空间维数理解指标；接近零的谱会带来分类不确定性。

## 4.3 表单与 JSON

修改任务名称、参数和资源后，点击 **“保存参数到草案”**。提交和附带草案以 JSON 编辑框为准，仅改表单还没有完成这一步。

高级用户可展开完整 JSON 编辑。网页也支持导入 30 KB 以内的任务 JSON；导入只成为草案，不自动提交。导入大小限制与 AI 可附带草案的大小限制不同，较大的 JSON 不一定能发送给 AI。

任务名称建议能区分模型和实验目的。研究说明写明希望回答的问题，避免放入访问令牌或个人隐私。

## 4.4 请 AI 建议修改

1. 保存参数到草案，勾选外部服务同意与“附带当前草案”。
2. 取消“附带选中任务”。
3. 在对话输入框写明具体改动。例如：“保持模型、算法和所有数值参数不变，仅将任务名称改为 demo-cubic。”
4. 点击输入框右下角的 **“生成配置草案”**，不要点击发送箭头。等待生成结束。
5. 在对话下方的“AI 配置草案”中检查改动清单和候选 JSON，确认后点击 **“应用到任务草案”**；不满意可丢弃。

发送箭头用于普通对话，可能返回文字建议，但不会生成可应用的改动清单。普通回答后输入框会清空；若要再生成草案，请重新输入修改要求。空输入时点击生成，网页会提示补充要求，不会调用 AI。

生成不会修改当前 JSON。应用只改变网页草案，仍没有开始计算。生成期间若改动了表单或 JSON，网站会拒绝覆盖新修改，需重新生成。

目前 AI 只能建议一组允许字段，不会直接切换物理模型或算法。若问题需要澄清，可能只返回说明而没有改动。参数通过程序检查，也不代表模型适合研究问题或求解一定收敛。

# 5. 复核、确认与计算

点击“提交方案复核”后，任务进入侧栏。服务器领取并检查输入、实现与资源；领取可能需要约两分钟，实际等待取决于服务状态。

复核就绪后，打开任务，阅读方案，重点检查模型、维数、算法、初始点、指标、时间和资源预算。只有勾选确认并点击开始计算，任务才进入计算队列。方案过期时应复制参数到新草案重新提交。

| 页面状态 | 下一步 |
|---|---|
| 等待校内复核 / 校内正在复核 | 等待，不反复创建相同任务 |
| 等待你确认 | 阅读完整方案，确认后计算 |
| 已确认，等待计算 / 计算中 | 查看进度与最近日志 |
| 上传结果中 | 等待文件处理完成 |
| 计算完成 | 检查结果与验证摘要 |
| 结果需检查 | 阅读检查理由，不直接当成有效研究结论 |
| 被校验阻止 | 看具体输入或资源原因，修改新草案 |
| 失败 / 超时 / 资源达到上限 / 已中断 | 检查失败阶段与已有输出，决定是否另建任务 |
| 已取消 | 如需继续，另建并确认任务 |

取消是请求，服务器收到后才处理。退出登录、关闭网页或网页等待超时，都不等于取消计算。系统不会因中断自动重算。

# 6. 结果、日志与下一次计算

## 6.1 先检查什么

先看状态与错误，再看节点数量、节点验证、残差与指标分类。不同指标层级同时出现可能是解景观搜索的正常结果，不应直接认为目标不一致。

**“计算完成”不等于“景观完整”。** 已返回节点通过验证，只说明这些节点通过相应检查；没有找到的节点不能因此排除。`landscape_complete` 缺失或为 null，不能解释为已证明完整。

搜索连接表示搜索过程中建立的关系，不自动等于物理转变路径、流线验证通过或最小能量路径。日志中的某次残差也不一定是最后验收残差。样本节点不能代表全部节点。

可以勾选附带任务，让 AI 解释摘要，但最终判断应以实际参数、日志和独立数值检查为准。

## 6.2 导出记录与获取日志

“最近日志”显示求解器输出的末尾片段，并不是完整搜索过程。片段长度以任务记录为准。

“导出任务记录”下载 JSON 快照，包含任务信息、方案、近期监控、结果摘要与事件。它与“下载完整结果文件”是不同操作。JSON 字符串中的 `\n` 表示换行，不是日志丢失。

目前结果存储尚未开启，完整文件不能直接从网页下载。需要管理员核对计算服务器上的原文件；启用存储后也不会自动补传旧任务。请先保留导出的任务编号与记录，便于查找。

结果存储开放并且该任务成功上传文件后，“结果文件”中才会出现下载项；现有下载流程会做完整性校验。

## 6.3 从节点重新起算

任务有已验证节点时，可选择节点、扰动数组与目标指标，提交新任务。扰动维数应与模型一致。新的任务仍需复核与人工确认，不是直接修改已经结束的任务。

“复制参数为新草案”适合调整同一模型的实验设置。提交前使用新的任务名，便于比较。

# 7. 常见问题

**如何生成配置草案？** 普通发送不需要任务。生成草案需要当前配置 JSON，而不是已提交任务。载入模板、保存草案并勾选附带后，再点击生成。

**为什么回答里的参数与我刚改的不一致？** 检查是否保存参数到草案、是否附带本轮草案，以及是否把已提交任务与当前草案混用。让助手逐项复述本轮模型、维数和目标指标，核对回执。

**AI 等待超时后能马上再发吗？** 前端最多等待约 90 秒。停止等待不代表后台或供应商停止处理，也不代表额度已退回。先检查提示，避免立即重复发送。

**失败会扣额度吗？** 后端部分失败会尝试退回本次个人主模型次数，但供应商费用不是应用次数。网页超时无法单独证明退款；提示退回失败时联系管理员核对。

**计算时间与预期不同怎么办？** 先核对模型、参数、预算和任务状态。比较不同设备时，还需对齐实现版本和计时范围；把任务记录提供给管理员进一步排查。

**能上传论文或者保留多个聊天吗？** 当前未开放。任务 JSON 导入是配置入口，不是 AI 附件上传。多个历史对话和文件解析均在后续计划中。

**模型回答很长却不完整怎么办？** 留意长度或超时提示，保存问题与回答。不要把截断的配置建议直接应用，可联系管理员核对响应状态。

# 8. 反馈问题与延伸阅读

反馈时提供操作步骤、任务编号、页面状态、预期与实际表现。必要时附截图或导出的任务记录，删除令牌和不必要的个人信息。记录中的个人标识也应在对外转发前处理。

本手册介绍 AutoLandscape 的用户流程。进一步研究数值算法可阅读 [SaddleScape 项目文档](https://hisdpackage.github.io/saddlescape/)；软件包文档中的功能需结合网站实际模板与复核能力使用。

若只需首次上手，回到本手册开头，按“登录 → 提问 → 模板 → 草案 → 复核 → 确认 → 结果”的顺序走一遍即可。
